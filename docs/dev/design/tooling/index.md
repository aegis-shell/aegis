# Tooling

Tooling turns the written design system into an enforceable engineering
contract. It covers token ownership, component examples, automated checks,
and measurable adoption.

## Enforcement principle

Documentation names the contract, code represents it, and tests enforce its
relationships. A rule that depends entirely on reviewer memory remains
partial even when every current screen happens to match it.
